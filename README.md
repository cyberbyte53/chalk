# Chalk

Interactive lessons built from props, and Jugnu, an AI tutor (an agent on the board, on a hosted model). First target: NCERT Class 9 Maths, Chapter 1, in Hindi and English.

```bash
pnpm install
pnpm dev        # the learner app at http://localhost:5173 (phone width)
pnpm check      # typecheck, tests, validate content, lint
```

- Map of the repo: [docs/architecture.md](docs/architecture.md)
- Names: [docs/glossary.md](docs/glossary.md)
