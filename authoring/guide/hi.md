# Writing Hindi

DRAFT. How we write and speak Hindi, for whoever translates. The words themselves come from the chapter's
Hindi NCERT book (`authoring/books/<book>/<chapter>/source/hi/terms.yaml`), never from memory.

- **Address the student as तुम**: warm, as a teacher in class.
- **Plain spoken Hindi**, as a teacher says it in class, not formal written Hindi. Where the book has a
  term (भुज, कोटि, चतुर्थांश), use the book's term, exactly, every time.
- **Notation as the book writes it.** Points, axes and variables stay as the book prints them (often Latin
  letters: P, x-अक्ष); how each is read aloud is marked in the line (`[[x|एक्स]]`) until the chapter's
  the chapter's `source/hi/terms.yaml` says how the book's readers say it.
- **Same meaning, natural order.** Translate the sentence, not the words: Hindi word order, Hindi idiom; never
  a word-for-word English shape.
- **One name per thing**, as in English: the same Hindi word for the same idea across the whole chapter.

Open, to settle from the Hindi book and a reader's ear: how point names are read aloud ("P" as पी?), and
Roman numerals for quadrants (I, II) beside Devanagari text.
