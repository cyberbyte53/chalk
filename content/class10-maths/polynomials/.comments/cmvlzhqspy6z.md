  $t^2 - 3$ a factor of $2t^4 + 3t^3 - 2t^2 - 9t - 12$? Divide, one step at a time:
  $$\\begin{aligned} \\tfrac{2t^4}{t^2} = 2t^2 &: \\quad \\text{left } 3t^3 + 4t^2 - 9t - 12 \\\\
  \\tfrac{3t^3}{t^2} = 3t &: \\quad \\text{left } 4t^2 - 12 \\\\ \\tfrac{4t^2}{t^2} = 4 &: \\quad
  \\text{left } 0 \\end{aligned}$$ So $$\\begin{aligned} &2t^4 + 3t^3 - 2t^2 - 9t - 12 \\\\ &= (t^2
  - 3)(2t^2 + 3t + 4) + 0 \\end{aligned}$$ The remainder is 0, so yes."
