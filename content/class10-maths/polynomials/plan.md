# Class 10 Maths Ch 2: Polynomials — lesson plan

Approved 2026-10-18. Full edition (2.4 division algorithm kept, like Ch 1). Built against `content/principles.md`.

**Thread:** one zero, three views — where the value is 0, where the graph meets the x-axis, a factor (x − k).

**Props:** value machine (L2, L7) · graph explorer = zeroPlane with lift / flip / crossing count (L3, L9) · zero pair = zeroPlane by zeroes with sum and product shown (L5, L6) · factor box = polyBox, multiply (L4, L5) and divide (L8, L9).

| # | Lesson | Opens with | What she must understand |
|---|---|---|---|
| 1 | What is a polynomial | Tap every polynomial (NCERT's list) | Whole-number powers only, any coefficients; x = x¹, 5 = 5x⁰; degree = highest power wherever written; linear / quadratic / cubic; general forms; why a ≠ 0, b and c may be 0 |
| 2 | Value and zeroes | Ball h = 20t − 5t²: height at 1 s, when it lands (in the air only 0 to 4 s); then value machine on x² − 3x − 4 | p(k) by substituting; signs with negative inputs; zero = input giving 0; p(0) is not "a zero"; zero of ax + b is −b/a (2k + 3 = 0 first, then ak + b = 0; needs a ≠ 0) |
| 3 | Zeroes on the graph | The machine's dots join into the graph | Graph = points (x, p(x)); x-axis has y = 0, so crossings are zeroes; y-axis point is p(0), not a zero; line once; parabola 2 / 1 (touch) / 0, opens by sign of a; at most n because the curve must turn back to cross again; Ex 2.1 graphs |
| 4 | Zeroes from factors | Find the zeroes of x² − 3x − 4 without trying numbers | Product 0 only when a factor is 0; factor x − k gives zero k; divide by the coefficient (2x − 3 → 3/2); splitting the middle term: two parts that add to b and multiply to first × last (box diagonals); no constant term, difference of squares (surds), perfect square (one zero = touch); standard form first |
| 5 | Zeroes and coefficients | Pattern hunt: four quadratics and their zeroes | α, β names; sum = −b, product = c (a = 1) found first; why: (x − 2)(x − 3) then (x − α)(x − β), same steps; matching coefficients; a ≠ 1: take a out, zeroes don't move → −b/a, c/a; "verify" = both sides; traps: minus, ÷a, standard form |
| 6 | A quadratic from its zeroes | "Zeroes add to −3 and multiply to 2: write it" | x² − (sum)x + (product); any k ≠ 0 keeps the zeroes (k × 0 = 0); k clears fractions; sum 0 → no x term; Ex 2.2 Q2 |
| 7 | The cubic | "Are 4, −2, ½ the zeroes of 2x³ − 5x² − 14x + 8?" | Substituting fractions; three zeroes are all of them; "pairs" = every pair multiplied and added; −b/a, c/a, −d/a; signs −, +, − from one more factor; Ex 2.4 |
| 8 | Dividing polynomials | "51 = 21 × 2 + 9; divide 2x² + 3x + 1 by x + 2 the same way" | Match first term, multiply back, take away; taking away a negative adds; stop when remainder's degree < divisor's; descending order, 0x gaps; check by multiplying back; long-division layout for exams; NCERT Examples 6–8, Ex 2.3 Q1 |
| 9 | Finding the other zeroes | "1 is a zero of x³ − 3x² − x + 3; find the rest" | Why a zero k makes x − k divide exactly (remainder = p(k) = 0); multiply known factors first (no surds), clear fractions with k; always factorise the quotient; remainder 0 = factor; Example 9, Ex 2.3 Q2–Q5 |

Prerequisite checks (signs, exponents, expanding brackets) sit inline where first needed, not as a review lesson.
