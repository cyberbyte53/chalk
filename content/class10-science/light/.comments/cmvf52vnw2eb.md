snapshot: "**Real and virtual.** If the rays **really meet** at the image, the image is **real**.
  Light actually gets there, so it can be caught on a screen, like a projector's picture on a wall.
  If the rays only **seem to come from** the image, it is **virtual**. No light gets there, so no
  screen can catch it: you can only see it by looking into the mirror."
