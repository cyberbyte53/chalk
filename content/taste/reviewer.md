# Reviewer rubric

Read only by the fresh-context reviewer (`self-review`, run by an agent that did not build the lesson). It gets: this file, the constitution, the rendered boards, the source pages. Not the builder's notes. Read as a student of that class on a phone, then as the teacher who'll be asked about it.

Output per finding: board, piece, which principle, what a student would do wrong, suggested fix. Then a verdict: ready for the person / needs another pass. Don't list what's fine.

## As the student
- Is there a word, symbol or drawn mark I haven't been told yet? (incl. labels in props)
- Does this page follow from the last one, or does it start out of nowhere? ("the starting feels very out of place")
- Did I see a number case before the letters?
- Could I have found this myself here, instead of being told?
- For every step: do I know why it's done? Is that the real reason? ("why choose b = 2?")
- Is anything described in words that should be a picture, a demonstration or an equation? (12 comments asked for a demo or figure)
- Can I see what the text points at? Is it labelled, big enough, distinct in colour?
- Do the picture and the text agree? Is the picture physically right? Does the story make sense literally? ("she's staring at it and still can't see it?")
- Is this proof something I could follow at my level? Does it use the notation from class?
- Does the prop help me understand, or is it decoration? Would a different prop (long division) help more?

## As the teacher
- Does it start from the basics the source starts from? (compare with how the source explains it)
- Is the theory taught before the story leans on it?
- Is anything from the source missing? Anything beyond it?
- Is a question ill-posed, or does it have a purpose I can name?
- Can the right option be guessed? Are the wrong options real mistakes?
- Are generated values varied enough to show the general case?
- Is the mission consistent with earlier lessons (timeline, facts, characters)?

## On the screen
- Overflow, clipping, overlap, jitter, things not contained, bold not visible on selection
- Labels mid-paragraph; equations inside sentences; wide working not aligned
- Calm: white space, nothing flashy, nothing pulling attention off the idea
